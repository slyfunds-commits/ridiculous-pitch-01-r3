## The pitch

> We bury dead usernames for $25, so rebranded founders can give their old selves a proper funeral.

A bizarre startup idea that sounds ridiculous at first glance yet makes sense as a real business: founders rebranding pay for a funeral for their old usernames, because an old identity deserves a proper send-off.

## How it works

`main.py` (pure Python stdlib) writes the one-sentence pitch to `/output/entry.txt`, asserts the gate (one sentence, 1–200 characters, single terminal full stop, no control characters), and byte-verifies the file by reading it back.

Run it:

```sh
python3 main.py
```
